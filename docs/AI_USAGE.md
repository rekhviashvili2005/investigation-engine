## 2. რაში დამეხმარა AI

**კოდის დიდი ნაწილი Claude-ის დახმარებით დაიწერა.** კერძოდ:

- პროექტის სტრუქტურა და ტექნოლოგიების არჩევის წინადადებები (Neon + pgvector, fastembed, Gemini, Streamlit, Render)
- ingestion: parsers, chunking სტრატეგიები, dedup, pipeline
- retrieval: BM25, weighted RRF, MMR, hybrid search
- LLM კლიენტი (retry/timeout), prompts, tool calling, agent ციკლი, პასუხის ვალიდაცია
- eval სკრიპტები და მეტრიკები, FastAPI, Streamlit UI, Dockerfile
- ტესტების პირველი ვერსიები
- README, Evaluation Report და ამ ანგარიშის ტექსტები
- თითოეული ნაწილის ახსნა, რომ გამეგო, როგორ მუშაობს

## 3. რა გავაკეთე მე

- **გარემოს აწყობა:** PyCharm, Python 3.12, venv, git, GitHub, Neon, Render, Colab და საიდუმლოების (Secrets) კონფიგურაცია
- **ყველა ბრძანების და სკრიპტის გაშვება** ჩემს კომპიუტერზე და Colab-ში; შედეგებს, შეცდომების ტექსტს და სკრინშოტებს Claude-ს ვუგზავნიდი დიაგნოსტიკისთვის
- **გადაწყვეტილებები:** რეკომენდაციებს ვადასტურებდი ან ვცვლიდი გარემოებების მიხედვით (მაგ. Hugging Face Spaces უარვყავი, რადგან Docker Space ფასიანი აღმოჩნდა, და Render-ზე გადავედი; მძიმე ჩატვირთვები Colab-ში გავიტანე, რადგან ლეპტოპი სუსტია)
- **ბაგების აღმოჩენა და გასწორება:** დაფარვის შემოწმებით დადასტურდა, რომ პირველი retrieval eval არასწორი იყო; eval გავუშვი მხოლოდ იმ კითხვებზე, რომელთა supporting პარაგრაფები ბაზაშია
- **წყაროების გადამოწმება:** post-mortem კითხვების მოსალოდნელი პასუხები დოკუმენტის ამონარიდებთან შევადარე; ნაკლებად დადასტურებული კითხვები ამოვიღე
- **უსაფრთხოება:** `.env` git-ში არ მოხვდა; საიდუმლოები ინახება Render Environment-სა და Colab Secrets-ში
- **მონაცემების ჩატვირთვა და მონიტორინგი** Colab-ში (HotpotQA, post-mortems)

## 4. AI-ის შეცდომები და შესწორებები

- პირველი რეკომენდაცია (Hugging Face Spaces, Docker) არ გამოდგა: ფასიანი აღმოჩნდა
- პირველი retrieval eval არასწორად იყო აგებული (`ORDER BY id`), რის გამოც recall ხელოვნურად დაბალი გამოვიდა
- ზოგი ბრძანება Windows/PowerShell-ისთვის არ იყო მორგებული და შესწორება დასჭირდა
- ჩატვირთვის სკრიპტი თავდაპირველად ნელი და ბაზასთან კავშირის გათიშვის მიმართ მგრძნობიარე იყო; გადავაკეთეთ (მოკლე კავშირები, გაგრძელებადობა, ბატჩები, პარალელური embeddings)
- კოდის ნაწილი თავდაპირველად გაშვებით შეუმოწმებელი იყო და გაშვების შემდეგ დაზუსტდა

## 5. როგორ ვამოწმებდი AI-ის გამოტანას

- ავტომატური ტესტები (pytest)
- რეალური გაშვება ბაზაზე და LLM-ზე
- eval მეტრიკები და შედეგების ხელით გადახედვა
- post-mortem კითხვების პასუხები დოკუმენტის ტექსტთან შედარებით
